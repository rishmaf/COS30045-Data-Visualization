STEP 2Understand the SVG Coordinate System

SVG uses a top-left origin (0, 0). The x-axis increases rightward and the y-axis increases downward. All shape positions are relative to this origin.

Exercise 4.5

Bind & Draw with Data
selectAll · data · join

Bind the loaded CSV data to SVG rectangles using D3's data join pattern. Use data values to set bar widths and position bars vertically — no scaling yet, raw pixel values.

STEP 1Bind Data to DOM Elements
const createBarChart = data => {
  svg.selectAll("rect")
     .data(data)
     .join("rect");
};
STEP 2Set Width & Height Attributes
.attr("width", d => d.count / 4)
.attr("height", 36)
.attr("fill", "#c8f060");
STEP 3Space Out the Bars
.attr("x", 0)
.attr("y", (d, i) => i * (36 + 10));

Exercise 4.6

Scaling Charts
scaleLinear · scaleBand

Make the chart adaptable to any SVG size. d3.scaleLinear() maps count values to pixel widths; d3.scaleBand() distributes categories evenly across the height with padding.

STEP 1Add a Linear Scale for Count Data (xScale)
const xScale = d3.scaleLinear()
  .domain([0, d3.max(data, d => d.count)])
  .range([0, innerWidth]);

.attr("width", d => xScale(d.count))
STEP 2Add a Band Scale for Categories (yScale)
const yScale = d3.scaleBand()
  .domain(data.map(d => d.screen_tech))
  .range([0, innerHeight])
  .padding(0.3);
LIVE D3 OUTPUT — scaled with scaleLinear + scaleBand
Exercise 4.7

Adding Labels
Groups, Category & Value Labels

Group bars and labels together with <g> + transform/translate so they move as one unit. Add category names on the left and count values to the right of each bar.

STEP 1Comment Out Rectangle Attributes

Temporarily comment out the rectangle's .attr() calls — you will re-add them inside a group.

STEP 2Add a Group Container (barAndLabel)
const barAndLabel = svg
  .selectAll("g").data(data).join("g")
  .attr("transform", d =>
    `translate(0, ${yScale(d.screen_tech)})`);
STEP 3Add Back Rectangles + Category & Count Labels

Category label

barAndLabel.append("text")
  .text(d => d.screen_tech)
  .attr("x", -8)
  .attr("text-anchor", "end");

Count label

barAndLabel.append("text")
  .text(d => d.count)
  .attr("x", d =>
    xScale(d.count) + 6);

Exercise 4.3

D3 Setup
SVG Canvas & Test Rect

Set up the D3 scaffolding — a responsive SVG container with a viewBox, and a hard-coded test rectangle to confirm D3 is working before adding data-driven bars.

STEP 1Clean Slate — Remove Old D3 Code

Delete any D3 code from Exercise 4.2 except the D3 library <script> tag and the link to your D3 JS file.

STEP 2Responsive SVG Container — CSS + HTML

Add a CSS class and a container div to make the SVG scale with the window.

style.css

/* makes container responsive */
.responsive-svg-container {
    margin-right: auto;
    margin-left: auto;
    width: 100%;
    max-width: 1200px;
}

index.html

<!-- container for D3 SVG -->
<div class="responsive-svg-container">
</div>
STEP 3Create SVG Object with viewBox

Use D3 to append an SVG. The viewBox makes the canvas scale proportionally to any window size.

const svg = d3.select(".responsive-svg-container")
    .append("svg")
      .attr("viewBox", "0 0 1200 600")
      .style("border", "1px solid black");

// Resize the window — the box scales with it.
STEP 4Append a Test SVG Rectangle

Confirm D3 is wired up by appending a hard-coded rectangle. Resize the window to watch the viewBox scale.

// Hard-coded test — no data yet
svg
  .append("rect")
    .attr("x", 10)  .attr("y", 10)
    .attr("width", 414)  .attr("height", 16)
    .attr("fill", "#c8f060");
LIVE D3 OUTPUT — test rect rendered by D3
DOMWhat the Browser Developer Tools Show

Open DevTools (F12) → Elements. D3 has injected an <svg> containing the <rect>:

<div class="responsive-svg-container">
<svg viewBox="0 0 1200 600">
<rect x="10" y="10" width="414" fill="#c8f060"/> ← test rect
</svg>
</div>

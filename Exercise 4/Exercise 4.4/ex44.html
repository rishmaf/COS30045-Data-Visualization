Exercise 4.4

Load CSV Data
d3.csv() & Formatting

Learn how to load and format CSV data so it is ready for D3. Use d3.csv() with a row conversion function to ensure numeric data is typed correctly, then find key statistics about the dataset.

PREPSet Up a Data Folder

Create a data/ folder in your project. The file data/tvScreenTechCount.csv is already included in this zip. It contains three rows: LCD, LCD (LED), and OLED counts.

STEP 1Load CSV with d3.csv()

The row conversion function (second argument) runs for every row. Use the unary + operator to coerce string values to numbers.

d3.csv("data/tvScreenTechCount.csv", d => {
  return {
    screen_tech: d.Screen_Tech,
    count: +d["Count(Brand)"]  // coerce to number
  };
});
